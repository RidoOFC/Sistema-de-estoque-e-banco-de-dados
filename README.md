# RidStoque - Sistema de Estoque com IA

Sistema de controle de estoque desenvolvido em Python/Flask.

##  Tecnologias
- Python (Flask)
- SQLite
- Inteligência Artificial (Google Gemini API)
- HTML/CSS/JS

##  Funcionalidade de IA
O sistema conta com um assistente de IA (localizado no canto inferior direito) que lê os dados do banco e gera relatórios executivos automáticos, apontando alertas de estoque baixo e insights financeiros.
